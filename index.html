01 / Primary

Full-Stack Product

PawPal

Pet Care Marketplace

Project ↗
Responsibility

Full-Stack Development · Backend · Database · Deployment

Technology

Next.js · React · TypeScript · NestJS · GraphQL · Apollo Client · MongoDB · Mongoose · Docker Compose · nginx

PawPal is a full-stack pet-care marketplace connecting pet owners with products, services, specialists, bookings, inquiries, community features, real-time messaging, and AI-assisted support.

The system supports User, Specialist, and Admin roles, JWT authentication with backend member validation, 14 MongoDB collections, and an OpenAI-powered assistant. Product and service discovery combines backend pagination and search with client-side category and location filtering.

  • Product / service marketplace and booking workflow
  • Role-aware authentication and member validation
  • Real-time chat, inquiries, community, and AI support
  • Docker Compose and nginx on an Ubuntu VPS

02 / Secondary

Commerce Platform

Venturo

Outdoor E-Commerce Platform

Project ↗ Web source ↗ API source ↗
Responsibility

Full-Stack Development · Commerce Logic · Deployment

Technology

React · TypeScript · Express.js · REST API · MongoDB · Mongoose · Socket.IO · PM2 · nginx

Venturo is a full-stack outdoor e-commerce platform covering product discovery, authentication, cart, checkout, orders, inventory management, and administrative operations.

The backend is the source of truth for price and stock. Checkout validates availability and quantity, calculates totals server-side, updates inventory, and creates the order with its items using transaction-safe behavior. Customer JWT and admin session flows remain separate.

  • Server-authoritative pricing and totals
  • Availability, quantity, and inventory validation
  • Transaction-safe order and order-item creation
  • Separate customer JWT and admin session flows
