Backend integrity

Engineering decisions

Live member validation
Authenticated requests re-check the current member record instead of trusting stale token data.
Minimal JWT payload
Tokens carry identity only: { _id } rather than copying the full member document into the token.
Account-state enforcement
BLOCK and DELETE member states are rejected during authenticated requests.
Backend validation
Sensitive operations are validated server-side rather than relying on client state.
